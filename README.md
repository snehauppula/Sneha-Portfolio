# Sneha Portfolio - Cinematic AI/DS Experience

This is a premium, high-fidelity developer portfolio designed for a Data Scientist and AI Engineer. Built with Next.js, Framer Motion, and Three.js, it features a unique "Neural Interface" aesthetic.

## 🚀 Features
- **Neural Hero**: 3D particle background with interactive "Neural Scan" AI overlays on profile images and mouse parallax.
- **Kinetic Storytelling**: About section with bold split-text reveals and sticky dynamic layouts.
- **Neural Ecosystem**: Interactive SVG skill graph with connected nodes and technical confidence metrics.
- **Stacked Parallax**: Project showcase where cinematic cards slide over each other with AI scan identifiers.
- **Neural Path**: A scrolling journey timeline that "lights up" with pulsing nodes.
- **System Sync**: Terminal-inspired "System Boot" loading screen and high-tech contact interface.
- **Custom Cursor**: Spring-physics multi-layered cursor with ambient glow.

## 🛠 Tech Stack
- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS v4
- **Animations**: Framer Motion, GSAP (ScrollTrigger)
- **3D/Graphics**: Three.js, React Three Fiber
- **Experience**: Lenis (Smooth Scroll), Lucide Icons

## 📦 Installation & Setup

1. **Clone & Install**:
   ```bash
   npm install
   ```

2. **Run Dev Server**:
   ```bash
   npm run dev
   ```

3. **Build Product**:
   ```bash
   npm run build
   ```
